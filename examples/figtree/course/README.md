# Course companion: Agentic AI with Langflow

A no-code class for health-plan staff, six modules, thirty labs. The companion page
(`course.html`, built by `build_course.py`) is written for readers who will never open a code
editor: each module has one capstone figure with a numbered reading, the labs as cards by tier,
why it matters in a health plan, the words to know, and a collapsed instructor checklist.

- `specs/`: one spec per capstone plus the six-module journey, in `../langflow/SPEC-FORMAT.md`.
  The evidence corpus is the curriculum excerpt the instructor supplied (`corpus/course.md`).
- `figures/`: generated by `python -m figtree digest --all -o figures --rubric teaching`
  (the journey with `--max-aspect 8` so it reads as one row); all seven score 9.0 to 9.9 with
  no critical issue.
- Accessibility: skip link, landmarks, every figure has an SVG title and description and a
  numbered reading in words, decisions and stores differ by shape as well as colour, focus is
  visible, motion respects the reduced-motion setting, phone width stacks to one column.

Rebuild: `python examples/figtree/course/build_course.py examples/figtree/course/course.html`.
