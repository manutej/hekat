UNDERSTANDING TEST RESULTS
════════════════════════════════════════════════════════════════════════════════

Confidence Score (0.0 - 1.0):
  0.0-0.3   = Need more data
  0.3-0.5   = Limited or volatile data
  0.5-0.7   = Reasonable prediction
  0.7-0.9   = Good prediction
  0.9-1.0   = Excellent prediction

Trend Classification:
  Increasing (>5%/period)   = Getting less efficient
  Stable (-5% to +5%)       = Consistent behavior
  Decreasing (<-5%/period)  = Getting more efficient

Alert Severity:
  Info (0-15% over)   = Normal variance
  Warning (15-30%)    = Investigate
  Critical (>30%)     = Immediate action

Consistency Score (0.0 - 1.0):
  0.0-0.3   = Highly unpredictable
  0.3-0.7   = Moderate volatility
  0.7-0.9   = Fairly predictable
  0.9-1.0   = Very stable

DEBUGGING TIPS
════════════════════════════════════════════════════════════════════════════════

Problem: Confidence seems low
Solution: Check sample size and consistency
  - Need 3+ samples for reasonable confidence
  - Check if data is volatile using consistency score

Problem: Prediction seems off
Solution: Verify data range
  - Prediction should be near average of history
  - Min history < prediction < max history

Problem: Trend not detected
Solution: Check trend magnitude
  - Trend needs >5% change rate to be "increasing/decreasing"
  - Small changes are classified as "stable"

Problem: Alert not triggering
Solution: Check budget threshold
  - Info: 0-15% over
  - Warning: 15-30% over
  - Critical: >30% over
