## Architecture Summary

### 4 Major Components

**1. Skill Discovery Engine**
- Scans 2 skill directories
- Parses SKILL.md metadata
- Builds affinity matrix
- Indexes 70+ skills
- Output: Ranked skill list

**2. Requirement Analyzer**
- Extracts domains from task
- Scores skills by relevance
- Creates affinity scores
- Ranks recommendations
- Output: Top 10+ scored skills

**3. Skill Injector**
- Selects up to 5 skills per agent
- Calculates token costs
- Adjusts quality targets
- Merges skill documentation
- Output: Agents with skill context

**4. Pattern Extractor**
- Identifies applied patterns
- Extracts code examples
- Collects best practices
- Organizes artifacts
- Output: Enriched deliverable

### Workflow Integration

**Standard IMPLEMENTATION Workflow**:
```
extract → duplicate → design || implement || integrate
→ harmony → refine[0.85] → criticize → synthesize → extract
```

**Super Mode IMPLEMENTATION Workflow**:
```
extract → discover_skills → analyze_domains
→ duplicate[+skills] → design[skill-context] || implement[+skills] || integrate[+skills]
→ harmony[skills] → refine[0.88] → criticize[+skills] → synthesize[patterns] → extract
```

**Key differences**: 2 new phases (0.0, 0.5), skill injection at all stages, higher quality target
