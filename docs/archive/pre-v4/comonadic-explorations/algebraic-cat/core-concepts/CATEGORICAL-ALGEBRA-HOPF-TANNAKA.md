# Categorical Algebra: Hopf Algebras and Tannaka-Krein Duality

## Introduction: Symmetries and Categories

**Central question**: How do algebraic structures (groups, rings) capture symmetries?

**Categorical answer**: Via **Hopf algebras** - algebraic structures with categorical representation theory.

**Key insight**: A Hopf algebra is defined by its **representation category**, not by operations.

## Hopf Algebras: Definition and Structure

### The Four Operations

A **Hopf algebra** H over field k is an algebra with four operations:

**1. Multiplication**: m: H ⊗ H → H (group multiplication)
```
(ab)c = a(bc)  [associativity]
1·a = a = a·1  [identity element]
```

**2. Comultiplication**: Δ: H → H ⊗ H (dualization - how to copy)
```
Δ: h ↦ h_(1) ⊗ h_(2)  [Sweedler notation]
(Δ ⊗ id) ∘ Δ = (id ⊗ Δ) ∘ Δ  [coassociativity]
```

**3. Counit**: ε: H → k (evaluation)
```
(ε ⊗ id) ∘ Δ = id  [left counit]
(id ⊗ ε) ∘ Δ = id  [right counit]
```

**4. Antipode**: S: H → H (inverse operation)
```
m ∘ (S ⊗ id) ∘ Δ = η ∘ ε  [left inverse]
m ∘ (id ⊗ S) ∘ Δ = η ∘ ε  [right inverse]
```

### Axioms Unified

```
Compatibility: Δ, ε are algebra homomorphisms
              m, η are coalgebra morphisms

Consequence: (H, m, η) algebra AND (H, Δ, ε) coalgebra coexist
```

## 25+ Examples

### 1. Group Algebra k[G]
```
H = k[G] = vector space with basis {e_g | g ∈ G}

Multiplication: e_g · e_h = e_{gh}
Comultiplication: Δ(e_g) = e_g ⊗ e_g
Counit: ε(e_g) = 1 ∈ k
Antipode: S(e_g) = e_{g^{-1}}

Representation: Rep(k[G]) = G-modules
```

### 2. Universal Enveloping Algebra U(𝔤)
```
𝔤 = Lie algebra [x,y] = xy - yx
H = U(𝔤) = tensor algebra with [x,y] relations

PBW theorem: U(𝔤) ≅ polynomial algebra
Comultiplication: Δ(x) = x ⊗ 1 + 1 ⊗ x  [primitive element]
Antipode: S(x) = -x

Representation: Rep(U(𝔤)) = 𝔤-modules = Lie algebra representations
```

### 3. Quantum Group U_q(sl_2)
```
Generators: e, f, h (Chevalley)
Relations: [h,e] = 2e, [h,f] = -2f, [e,f] = (q^h - q^{-h})/(q - q^{-1})

Comultiplication:
  Δ(h) = h ⊗ 1 + 1 ⊗ h
  Δ(e) = e ⊗ q^h + 1 ⊗ e
  Δ(f) = f ⊗ 1 + q^{-h} ⊗ f

Deformation: U_q(sl_2) = deformation of U(sl_2) by parameter q
```

### 4. Sweedler's H_4

## Representation Categories

### The Category Rep(H)

**Objects**: H-modules (vector space V with H action)

**Morphisms**: H-linear maps (respect action)

**Tensor Structure**:
```
V ⊗ W has action: h · (v ⊗ w) = Δ(h) · (v ⊗ w)
                               = h_(1) · v ⊗ h_(2) · w
```

**Key property**: Tensor product is **monoidal** because Δ is coassociative!

### Rigid Monoidal Structure

**Duality**:
```
For any V ∈ Rep(H), dual V* = Hom_k(V, k)

Evaluation: V* ⊗ V → k
Coevaluation: k → V ⊗ V*

Both defined using antipode S!
```

**Consequence**: Rep(H) is **rigid monoidal** (every object dualizable)

### Monoidal Functor to Vect

**Forgetful functor** U: Rep(H) → Vect_k
- Forgets H-action
- Preserves tensor product (monoidal)
- Has right adjoint (free module)

## Tannaka-Krein Duality: Reconstruction

### The Big Picture

```
Hopf algebra H
     ↓
Rep(H) [representation category]
     ↓
Fiber functor F: Rep(H) → Vect_k
     ↓
Tannaka duality reconstructs H from (Rep(H), F)
```

### Tannaka Reconstruction Theorem

**Statement**:
Given:
- Abelian monoidal category C
- Monoidal functor F: C → Vect_k (fiber functor)
- Certain finiteness/rigidity conditions

Then:
```
H = Nat(F, F)^op  [natural endomorphisms form Hopf algebra]
C ≅ Rep(H)        [original category recovered]
```

**Key insight**: Algebra IS determined by its representation category!

### Reconstruction Formula

```
H = End(F)^* = {μ: F ⇒ F | natural}

Explicitly:
H = colim_{V ∈ C} Hom(V, V)^*  [coproduct of all endomorphisms]

Hopf structure:
m: H ⊗ H → H given by composition
Δ: H → H ⊗ H given by tensor product splitting
ε: H → k given by evaluation at identity
S: H → H given by adjoint/dual
```

### Correspondence Table

```
Hopf algebra side    ←→    Category side
─────────────────          ──────────────
H (algebra)          ←→    (Rep(H), ⊗)
Δ: H → H⊗H          ←→    Tensor product on modules
ε: H → k            ←→    Forgetful functor
S: H → H (antipode) ←→    Duality/dual module
Grouplike g          ←→    Simple object decomposition
Primitive x          ←→    Morphisms between objects
```

## Rigid Monoidal Categories

### Complete Definition

Monoidal category C with left and right duals:

```
For each X ∈ C: left dual X* and right dual *X

Evaluation (right):     X* ⊗ X → I
Coevaluation (right):   I → X ⊗ X*

Evaluation (left):      X ⊗ *X → I
Coevaluation (left):    I → *X ⊗ X

Snake laws:  (both sides)  [diagram commutative]
```

### Rigid ≠ Braided ≠ Symmetric

```
Rigid: Every object has dual
Braiding: Natural isomorphism X⊗Y ≅ Y⊗X with hexagon axiom
Symmetric: Braiding is self-inverse (β_Y,X ∘ β_X,Y = id)

Relationship:
Symmetric ⟹ Rigid monoidal ⟹ Monoidal
Braided + Rigid ⟹ Ribbon (with twist)
```

### Examples

**Rigid**: Rep(H) for any Hopf algebra, Finite-dim Vect

**NOT Rigid**: Infinite-dimensional Hilbert spaces (no duals)

## Quantum Groups and Yang-Baxter Equation

### Deformation Theory

**Drinfeld-Jimbo**: Quantum groups as deformations

```
Classical: U(g) with [x,y] = xy - yx
Quantum:   U_q(g) with [x,y] = (q^h - q^{-h})/(q-q^{-1})

Limit: q → 1 recovers classical limit
Deformation: respects Hopf structure
```

### Quasitriangular Structure

**R-matrix**: R ∈ H⊗H satisfying Yang-Baxter equation

```
Braiding: β_{V,W} = R acts on V⊗W
R ∈ U_q(g)⊗U_q(g) universal R-matrix

Yang-Baxter equation:
(R⊗1)(1⊗R)(R⊗1) = (1⊗R)(R⊗1)(1⊗R)  [in H⊗H⊗H]
```

### Classical Yang-Baxter Equation

In Lie algebras:
```
[r₁₂, r₁₃] + [r₁₂, r₂₃] + [r₁₃, r₂₃] = 0

r ∈ g⊗g classical r-matrix
```

**Origins**: Integrable systems in statistical mechanics

### Solutions and Classification

**Six-vertex model**: R-matrix satisfying QYBE with special structure

**Classification (finite-dimensional)**:
- At generic q: Unique (up to equivalence)
- At roots of unity: Multiple solutions
- Dimension 2: 96 distinct solutions

## Braided Tensor Categories

### Braiding

**Braiding isomorphism**:
```
β_{V,W}: V ⊗ W → W ⊗ V

Hexagon axioms (2-category coherence):
(β ⊗ id) ∘ α ∘ (id ⊗ β) = α ∘ β ∘ α  [commutative in proper sense]
```

### Fusion Categories

**Semisimple** abelian tensor categories:
```
Simple objects: X₁, X₂, ..., X_n
Fusion rules: X_i ⊗ X_j = ⊕_k N^k_{ij} X_k

Dimension: dim(C) = ∑(dim X_i)²
```

### Examples

1. **Vec_G**: G-graded vector spaces (dimension |G|)
2. **Rep(G)**: Finite group representations (dimension |G|)
3. **Rep(U_q(sl_2))**: Quantum group (dimension depends on deformation)
4. **Fibonacci**: Simplest non-group fusion (dimension φ²)
5. **Tambara-Yamagami**: Explicit non-symmetric fusion

## Topological Quantum Field Theory

### Atiyah-Segal Axioms

TQFT is symmetric monoidal functor:
```
Z: (Bord_d) → (Vect)

Bordism category: objects = (d-1)-manifolds, morphisms = d-cobordisms
Vector space category: standard

Multiplicative: Z(M₁ ⊔ M₂) = Z(M₁) ⊗ Z(M₂)
Functorial: Composition preserved
```

### Reshetikhin-Turaev Construction

From **modular tensor category** C:
```
Z: Bord₃ → Vect_k

For each closed 3-manifold M:
Z(M) = vector space from ribbon graphs in M

Invariant: Independent of triangulation (TFT axiom)
```

### WRT Invariants

**Witten-Reshetikhin-Turaev invariants**:
```
τ_k(M) = Z(M) ∈ k

From U_q(sl_2) at q = exp(2πi/(k+2))

For q root of unity: Non-trivial invariant
```

**Example**: Trefoil knot has WRT invariant computed from quantum group

## Categorical Quantum Mechanics

### Dagger Categories

**Dagger structure**: f† = adjoint of f

```
Satisfies:
(f†)† = f
(f ∘ g)† = g† ∘ f†
(f ⊗ g)† = f† ⊗ g†
```

### Dagger-Compact Categories

Rigid monoidal categories with dagger:
```
V* = adjoint of V
Evaluation: f†

Teleportation, entanglement from dagger structure
```

### ZX-Calculus

**Graphical quantum computing**:
```
Spiders: |⟩ and green colored vertices
Generators: Z (red), X (green) spiders
```

## Knot Invariants from Quantum Groups

### Jones Polynomial

For knot K:
```
J(K)(q) = formal Laurent polynomial in q

Computed from:
- U_q(sl_2) representation
- R-matrix (Yang-Baxter)
- Trace over link diagram
```

**Example**: Trefoil
```
J(trefoil)(q) = q⁻¹ - 1 + q

Prove: trefoil ≠ unknot (unknot J = 1)
```

### Kauffman Bracket

**Skein relation**:
```
⟨trefoil⟩ = relations involving crossing changes
           = computable polynomial
```

**Connection to quantum groups**: Via representation theory
