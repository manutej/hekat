# Universal Properties

## Definition

**Universal Property**: Unique factorization through U

For morphism f: c → R and universal object U:
∃! g: c → U making f = u ∘ g (where u: U → R universal map)

## Three Perspectives

1. **Existence + Uniqueness**
2. **Representable Functor** (Hom(-,U) represents)
3. **Adjoint Functor** (universal via adjunction)

## Power of Universal Properties

- **Determine up to iso**: Objects characterized by their role
- **Exist automatically**: In appropriate categories
- **Compose naturally**: Universal → Universal = Universal
- **Enable proof transfer**: Via duality

## Connection to Adjoints

**Left adjoint = universal from codomain**
**Right adjoint = universal to domain**
