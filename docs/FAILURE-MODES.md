# Failure modes log

Every entry is a defect that appeared in a real run, with how it is detected, how it is now
prevented, and what an agent must still check by eye. Skills and worker briefs point here;
a new failure mode is added the day it is seen, before it is fixed.

How to add an entry: name the defect in the reader's words, say where it was seen, which check
catches it (or "eye only"), what now prevents it (code path and test), and what remains for the
eye. If nothing prevents it yet, write "Open:" and the planned fix; the handoff lists open rows.
