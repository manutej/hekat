HEKAT × JEV

What we wired: a typed classification & fail-closed gate on top of the HEKAT orchestration DSL, so an agent pipeline isn’t just planned — it’s classified, gated, triaged, and recorded on a durable tape.

01

The idea in one line

HEKAT plans

A DSL that composes agents with operators (-> sequential, || parallel, ? fallback, ^ ensemble). It compiles a query into a DAG with phases and an L1–L7 complexity/token budget. Powerful, but static: it never asks whether a composition is allowed or useful.

JEV judges

A double-operadic type system (Libkind–Myers, arXiv:2505.18329). It classifies elements into five colors, composes only on a color match (γ), and scores a shipping gate that fails closed. It supplies the decision; HEKAT supplies the plan.

Net effect: HEKAT becomes useful at runtime — classifying agent outputs, gating hand-offs, and directing triage (ship / clarify / re-route), all recorded durably.

03

Five colors = the domain language

Every element (agent, skill, prompt) is classified into one interface color. The ~color modifier lets you assert it inline; otherwise a lexicon or the live model decides.

E entity

Named things: tables, tokens, people.

C concept

Interfaces, types, modules, doctrines.

I idea

Hypotheses, claims, theories.

V evidence

Queries, counts, catalogs, checks.

A action

Publish, compose, deploy, grant.

04

The fail-closed gate

A color distribution is scored against thresholds τ_green=0.72, τ_toxin=0.12, τ_red=0.4. The verdict maps straight onto a triage branch and a HEKAT control path.

GREEN
ship → compose
allowed ≥ 0.72 & toxin ≤ 0.12 & no seam
Proceed to the next phase.
AMBER
hold → escalate
0.4 ≤ allowed < 0.72, or a γ seam
Ask a human / clarify. Don’t ship.
RED
block → refuse
toxin > 0.12, or allowed < 0.4
Fail closed → re-route via ? fallback.

Go live — set the TypeSafe key

No env var is set on any JEV project yet. Home it on the volumetric-intelligence Vercel project (team …wfsWtUP7d1zIRArAwhlTUidB). Then HEKAT auto-consumes it.

  1. Add the key on Vercel (once): 
    vercel link      # team …TUidB · project volumetric-intelligence
vercel env add TYPESAFE_API_KEY production
  2. Pull it into local runtime from the repo root: 
    vercel env pull .env   # writes TYPESAFE_API_KEY (gitignored)
  3. Verify — the banner flips to LIVE: 
    python3 hekat_orchestrate.py --status
# classify=LIVE (TypeSafe API) · … · env=.env

Quick alternative: export TYPESAFE_API_KEY=… in your shell — same effect. Full detail in docs/GO_LIVE.md.
