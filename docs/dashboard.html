The five colors

Every element is classified into one interface color. The ~color DSL modifier lets you assert it inline.

E entity

Named things: tables, tokens, people.

C concept

Interfaces, types, modules.

I idea

Hypotheses, claims, theories.

V evidence

Queries, counts, checks, catalogs.

A action

Publish, compose, deploy, grant.
